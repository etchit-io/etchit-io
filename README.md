# etch / it

> *Etch it once. Fetch it forever.*

Permanent, decentralized text storage on the [Autonomi](https://autonomi.com) network. Open-source clients, one wallet identity, content that lives forever — no servers, no accounts, no takedowns.

| Client | What it does |
|---|---|
| **[Android](https://github.com/etchit-io/etchit)** | Etch · fetch · private etches · backups · chain/it sync |
| **[Desktop](https://github.com/etchit-io/etchit-desktop)** | Same flows · 13-language syntax highlighting · Linux today (Windows + macOS coming) |
| **[Web viewer](https://etchit.io/chainmarks.html)** | Read-only chainmark viewer — no install needed |
